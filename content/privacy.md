# Privacy Statement & Zero-Tracking Policy

*Last updated: October 17, 2026*

This website is designed and operated by **{{site.name}}** with an uncompromising commitment to privacy by design, minimal data collection, and software engineering transparency.

---

## 1. Zero Cookies & No Tracking

* **No Cookies**: This website does not set or read any cookies (first-party or third-party). 
* **No Analytics or Fingerprinting**: There are no tracking scripts, analytics suites (such as Google Analytics), advertising beacons, or browser fingerprinting mechanisms.
* **No Cookie Consent Banner Needed**: Because this site does not deploy tracking or analytical cookies, there are no intrusive popups or consent dialogs.

---

## 2. Local Storage Usage

The only client-side state saved on your device is your preferred user interface appearance:

* **Key**: `theme` (stored in your browser's `window.localStorage`)
* **Value**: `"light"` or `"dark"`
* **Purpose**: Retains your dark/light mode toggle preference across page visits.
* **Scope**: This data remains entirely within your local browser sandbox and is never transmitted to the server or any third party.

---

## 3. Server Access Logs

When accessing this website, the underlying web server automatically registers technical connection metadata in standard server access logs:

* **Logged Information**: Anonymized IP address, request timestamp, HTTP request method and resource path, HTTP status code, and HTTP User-Agent string.
* **Legal Basis & Purpose**: General Data Protection Regulation (GDPR) Art. 6(1)(f) — Legitimate Interest. These logs are processed strictly to ensure network stability, defend against denial-of-service (DDoS) attacks, detect security anomalies, and verify server integrity.
* **Retention**: Server logs are rotated regularly, retained only as long as necessary for technical security, and never correlated with personal user identities or shared with marketing entities.
